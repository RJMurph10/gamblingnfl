# NFL Edge Pro

Build me a website called GamblingNFL.

This will be my personal NFL statistics, analytics, and sports betting research platform.

Create a professional modern NFL analytics interface.

The first version should have:

A home dashboard

A Teams page showing all 32 NFL teams with their logos

Clickable team cards that open individual team pages

A Players page with searchable players

Individual player profile pages

A Games page

Individual game pages

Quarter-by-quarter statistics

Drive-by-drive information

Team statistics

Player statistics

A section for future betting predictions and player prop projections

Use a dark, professional sports-analytics design.

Make the website responsive so it works on both desktop and mobile.

Use Supabase as the backend/database. I already created a Supabase project called gamblingnfl and want this website connected to that project.

Do not fill the database with fabricated NFL statistics. Use placeholder/sample data only for the visual prototype until I connect real NFL data.

Structure the project so that I can eventually import large amounts of NFL play-by-play data and calculate my own statistical models with Python.
